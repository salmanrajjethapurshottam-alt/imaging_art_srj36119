IMAGINGARTS WEBSITE - UPDATED CLIENT PORTFOLIO

Open index.html in a browser (or deploy the whole folder to Netlify). Keep the assets folder beside index.html.

HOW TO ADD A CLIENT / CASE STUDY
1. Create a folder inside assets/images/case-studies/, e.g. assets/images/case-studies/new-client/.
2. Add the client's images there. Use JPG for photos and PNG for transparent logos.
3. Open assets/data/case-studies.js. Copy one project object in window.IMAGINGARTS_CASE_STUDIES and change its id, name, category, description, services, cover and images.
4. Use a unique lowercase id with hyphens. Image paths are relative to index.html.
5. Save and refresh the website. The filters and project detail gallery update automatically.

You can add partner logos in window.IMAGINGARTS_CLIENT_LOGOS and extra profile images in window.IMAGINGARTS_PROFILE_GALLERY in the same file.

THEME
The gallery includes the profile photographs, client project photographs, extracted partner logos, the complete client-wall spread, the other-customer wall, and both ESON spread pages. Decorative transparent layout layers are represented in the complete page spreads rather than shown as separate empty thumbnails.

The existing ImagingArts charcoal, navy and crimson design is retained. The new layout adds filters, case-study detail modals, image lightboxes, responsive galleries, and separate client-logo / profile-visual sections.
